# excuse-generator
Department of Excuses — a bureaucratic "case filing" web app disguised as an official government form. Pick a delinquency category (Work, School, Social, Family), hit Generate Excuse to watch one type itself out typewriter-style with clacking sound effects, then stamp it APPROVED or DENIED with a satisfying thud. Every verdict gets filed in a running Case File (saved locally), complete with an ever-climbing case number. Click the seal 5 times to unlock a classified excuse category, and don't click "Feedback."
